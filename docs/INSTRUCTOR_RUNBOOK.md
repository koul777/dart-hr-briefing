# DART HR Briefing 강사용 운영 런북

## 운영 목표

4시간 안에 모든 참가자가 다음 골든패스를 한 번 재현하도록 운영합니다.

```text
m0 환경·안전 확인
→ m1 기업·연도·보고서 선택
→ m2 합성 데이터 우선, 이후 OpenDART 비교와 근거 확인
→ m3 Strategy Brief와 안전한 AI 질문
→ m4 GitHub 저장과 Vercel 공개 URL 검증
```

이 과정은 완성형 앱을 기준으로 한 수정·검증 실습입니다. 백엔드와 프론트엔드를 빈 폴더에서 모두
새로 만드는 과정이 아닙니다. 실제 직원·지원자 개인정보는 어떤 단계에서도 입력하지 않습니다.

강의 자료는 **본문 42장·부록 18장·총 60장** 편성입니다. 본문 42장만 아래 4시간 시간표대로
진행하고, 부록 18장은 질문·장애 복구·심화 확인 때만 엽니다.

### 사람/AI 역할 경계

- **사람의 역할**은 입력 범위 선택, AI 전송 동의, 공시 원문·근거 확인과 최종 판단 책임입니다.
- **AI의 역할**은 공개 기업 단위 집계의 근거 있는 요약·해석 초안입니다. 개인 평가, 인과 단정,
  자동 채용·승진·보상·감축 등 자동 인사조치를 결정하거나 권고하지 않습니다.
- 강사는 AI 답변의 유무가 아니라 근거 ID·한계·사람의 검증 행동이 남았는지를 통과 증거로 봅니다.

## WEEK 1→2→3 연결과 강사 수용 기준

| 주차 | 산출물 | 학습 연결 |
| --- | --- | --- |
| WEEK 1 면접 브리핑 에이전트 | 지원 자료에서 구조화한 질문·확인 항목 | 개인 합격 예측이 아니라 검증할 질문 구조를 WEEK 2로 가져옴 |
| WEEK 2 DART HR Analytics 에이전트 | 공개 기업 공시의 근거·한계·결정 브리프 | 결정 브리프의 `다음 내부 데이터`를 WEEK 3 요구사항으로 넘김 |
| WEEK 3 데이터 빌더 | 합성 데이터로 정의한 필드·단위·집계수준·품질 규칙 | 개인정보 없이 내부 데이터 구조와 진단 도구를 검증 |

`ready`는 성공확률이나 인사조치 권고가 아니라 정의된 공시 비교의 **근거 이용 가능성**을 뜻합니다.
결정 브리프의 `다음 내부 데이터`는 WEEK 3 데이터 빌더의 입력으로 이어지지만, 실제 직원·지원자
데이터를 넘기라는 뜻이 아닙니다. 수업에서는 합성 사례의 필드 정의와 검증 규칙으로만 변환합니다.

강사 수용 기준:

1. 참가자가 `ready`를 “결정 성공”이 아니라 “정의한 공시 비교에 필요한 근거를 이용할 수 있음”으로 설명합니다.
2. 결정 브리프 하나의 `다음 내부 데이터`에서 필드명·단위·집계수준·검증 규칙을 적은 WEEK 3 입력 카드 한 장을 만듭니다.
3. 카드와 설명에 실제 개인정보, 성공확률, 개인 채용·승진·보상·감축 등 인사조치 권고가 없습니다.

## m0~m4 체크포인트 계약

체크포인트 이름은 교육 릴리스의 논리적 계약입니다. 실제 Git 태그나 브랜치를 제공할 때는 강의일과
릴리스를 포함한 이름을 사용하고, 존재하지 않는 참조를 안내하지 않습니다.

| 체크포인트 | 참가자 화면·산출물 | 통과 기준 | 실패 시 복구 |
| --- | --- | --- | --- |
| `m0` 환경·안전 | preflight 결과와 앱 첫 화면 | FAIL 0개, 정확한 앱 ID, `.env` Git 제외 | 패키지 실행 파일 사용 또는 조교 설치 좌석으로 이동 |
| `m1` 선택 UI | 삼성전자·SK하이닉스, 연도·사업보고서 | 두 기업이 중복 없이 선택되고 조건 변경 시 이전 결과 무효화 | m1 체크포인트를 별도 폴더/워크트리로 열고 현재 작업 보존 |
| `m2` 데이터·근거 | 합성 bootstrap, Overview·Compare·People·원문 링크 | 합성 워터마크, 결측과 0 구분, 기업·연도·단위·출처 확인 | 합성 bootstrap 응답과 준비된 실제 화면으로 해석 실습 지속 |
| `m3` Strategy·AI | Decision Brief, 품질 게이트, AI 또는 안전한 대체 응답, WEEK 3 입력 카드 | 사실·계산·가설 구분, `ready`의 근거 이용 가능성 설명, `다음 내부 데이터`의 합성 필드 변환, 개인판단·인과 단정 없음 | AI 호출 생략, 결정론적 Strategy Brief와 검증 대체 응답 사용 |
| `m4` 저장·배포 | GitHub 주소, Vercel 주소, 최종 캡처 | 비밀정보 미포함, 공개 URL과 `/api/health` 정상 | 강사 배포 URL로 검증 후 개인 배포는 사후 과제로 전환 |

현재 작업을 잃지 않는 복구가 원칙입니다. `reset --hard`나 기존 폴더 덮어쓰기를 안내하지 않습니다.
체크포인트 참조가 실제로 존재할 때만 다음처럼 별도 worktree를 만듭니다.

```powershell
git status --short
git rev-parse --verify <checkpoint-ref>
git worktree add ..\dart-recovery-m2 <checkpoint-ref>
```

태그가 없거나 Git 사용이 어려우면 강사가 제공한 체크포인트 ZIP을 새 폴더에 풉니다. 참가자의 기존
폴더는 그대로 둡니다.

공개 Vercel의 서버 키를 전원이 동시에 호출하게 하지 않습니다. 현재 앱의 기본 요청 제한은
프로세스당 30회/분이며 분산 전체 한도를 보장하지 않습니다. 실데이터는 강사 시연과 참가자별 최소
검증으로 제한하고 합성 데이터 실습을 먼저 진행합니다.

각 HTTP 요청 안의 OpenDART fan-out은 기본 35초·실제 네트워크 시도 48회에서 중단되며 캐시 hit는
시도를 소모하지 않습니다. 부분 결과의 “범위를 줄이고 다시 시도” 안내가 나오면 기업 수나 연도
범위를 줄여 한 번만 재시도하고, 다시 제한되면 합성 모드로 전환합니다.

합성 계약은 다음처럼 확인합니다. 이 경로는 외부 OpenDART·AI provider를 호출하지 않습니다.

```powershell
$sample = Invoke-RestMethod http://127.0.0.1:8765/api/classroom/bootstrap
$sample.sample
```

`enabled=True`, `network_requests=0`, `contains_real_company_data=False`,
`contains_personal_data=False`, `watermark="SAMPLE — SYNTHETIC DATA"`가 모두 확인되어야 합니다.
첫 화면에서 **합성 샘플로 시작**을 눌러 두 가상 기업, 고정된 기준연도·보고서,
`SAMPLE — SYNTHETIC DATA` 배너와 `외부 호출 없음` 상태를 확인합니다. 참가자는 샘플 모드에서
**합성 결정 브리핑 만들기**까지 실행한 뒤, **실데이터 화면으로 돌아가기**로 라이브 화면을
초기화합니다. 버튼이 보이지 않으면 다른 빌드일 가능성이 있으므로 `/api/health`의 app ID와
build ID를 대조하고 최신 교육 릴리스를 다시 엽니다.

`외부 호출 없음`은 브라우저가 로컬 `/api/classroom/bootstrap`을 한 번 호출하지 않는다는 뜻이
아니라, 그 로컬 응답을 만드는 동안 OpenDART·AI provider로 나가는 요청이 0회라는 뜻입니다.
참가자는 사전점검에서 이 로컬 JSON 계약을 1회 확인할 수 있지만, 수업 중 DevTools·JSON 대조
시연은 강사만 수행하고 참가자는 **합성 샘플로 시작** 화면 상태로 통과합니다.
실데이터 AI 시연에서는 전송 안내 체크 전 요청이 중단되는지 확인하고, 종료 전
**AI 키·대화 연결 해제**로 키·연결·대화·동의가 함께 초기화되는지 검증합니다.

AI 차단 사유 중 `uncited_factual_claim`은 인용 없는 수치·사실 주장,
`unsupported_causal_assertion`은 공시 근거로 확인할 수 없는 인과 단정,
`automated_hr_action_recommendation`은 자동 채용·승진·보상·감축 등의 권고,
`protected_characteristic_judgment`는 성별·연령·장애 등 보호특성 기반 판단을 뜻합니다. 차단된
원문을 정답처럼 재사용하지 않고 검증된 근거 fallback으로 실습을 이어갑니다. 입력 식별자가 자동
마스킹되더라도 질문 의미가 달라질 수 있으므로 실제 개인 데이터 입력은 계속 금지합니다.

| 영역 | 배점 | 증거 |

- 70점 이상을 기본 통과로 봅니다.
- API 키 또는 개인정보 노출, 출처 없는 수치, 개인 평가·자동 인사조치 제안은 점수와 관계없이
  필수 게이트 실패입니다. 수정 후 재검토합니다.
- 외부 AI 장애로 대체 응답을 사용한 참가자는 AI 영역을 감점하지 않고 근거·한계 검증으로 평가합니다.

## 드레스리허설

1. 강사 PC가 아닌 깨끗한 Windows 사용자 계정에서 시작합니다.
2. 참가자 문서만 보고 저장소 준비부터 preflight까지 시간을 잽니다.
3. 네트워크 정상 경로로 m0~m4를 모두 실행합니다.
4. OpenDART 차단, AI 키 없음, 포트 점유, Git 권한 없음, Vercel 지연을 각각 강제로 가정해
   대체 경로를 실행합니다.
5. 초보 참가자 2명 이상이 13:45·14:45·15:45·16:40 체크포인트에 도달하는지 기록합니다.
6. 설명이 아니라 실제 조작 시간, 도움 요청 수, 5분 이상 정체 구간을 기록합니다.
7. 4시간을 넘기면 필수 골든패스 밖의 슬라이드를 부록으로 이동하고 다시 실행합니다.
8. PPT·문서·체크포인트·앱 커밋·공개 URL의 버전을 대조한 뒤 교육 릴리스를 동결합니다.

최종 승인 기준은 정상 경로 완주만이 아닙니다. 외부 API 두 가지를 모두 사용할 수 없는 상황에서도
개인정보 없이 m0~m3 학습목표를 달성하고, 참가자의 기존 작업을 잃지 않고 복구할 수 있어야 합니다.
