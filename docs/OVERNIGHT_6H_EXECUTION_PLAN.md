## 출시 차단 조건

아래 중 하나라도 충족하면 강의용 릴리스로 승인하지 않는다.

- CI가 빨간 상태이거나 지원 Python 버전 결과가 취소됨
- 합성 교실 모드에서 회사 선택 → 비교 → 전략 → 안전한 AI 결과 → 내보내기 흐름이 끊김
- 무근거 수치·사실 또는 자동 채용·평가·보상·감축·퇴출 권고가 통과함
- 개인정보가 AI provider outbound payload에 남음
- 배포 build ID를 확인할 수 없거나 강의 전 preflight가 실패함
- 강제 네트워크 지연/실패에서 사용자가 취소 또는 재시도할 수 없음
