# DART Workforce Intelligence — 시각화 QA 기록

## 목적

참고 HTML `기업 비교 대시보드_v1.html`의 시각 요소를 `Strategy Brief`에 동적으로 반영했는지 확인한다. 참고 HTML에 포함된 특정 기업의 수치는 하드코딩하지 않고 OpenDART 응답을 사용한다.

## 적용 항목

- `#0e1218` 기반 다크 패널과 `#151b24` 카드 계층
- 첫 번째·두 번째 선택 기업을 각각 블루·레드 계열로 구분하는 범례와 카드 강조
- 선택 기업명을 헤더에 동적으로 `기업 A vs 기업 B` 형태로 표시
- Strategy 활성화 시 상단바·사이드바·검색·AI 질문 영역도 참고 HTML 계열의 다크 테마로 전환하고 다른 탭에서 복귀
- Strategy 활성화 시 `theme-color` 메타도 다크 팔레트로 동기화
- Strategy 활성화 시 상단 intro도 `DART / WORKFORCE INTELLIGENCE` 및 인력·보상 벤치마크 문맥으로 전환
- AI 결과 패널도 provider 상태별 성공·handoff·오류 색상을 다크 팔레트로 표시
- 실제값은 실선/채움 막대, 모델 추정은 점선/해칭 막대로 구분
- 영업이익: 연도별 세로형 그룹 막대차트
- 평균 급여: SVG 추이선, 실제 구간, 점선 전망, 전망 범위 밴드
- Pay Equity: 공시값 카드와 공시 누락 상태를 별도 시각 상태로 표시
- Pay Equity: 여성 급여/남성 급여 비율을 수평 비율 바로 표시
- 내부 HR 데이터가 필요한 영역: 잠금 카드로 표시
- DART 원문, 품질 게이트, 에이전트 trace를 다크 근거 패널로 표시
- `AI 분석 질문`: `/api/analysis` 호출, Claude MCP provider 상태와 프롬프트 fallback 표시
- AI 질문 컨텍스트에 현재 People 요약과 Strategy에서 불러온 연도별 People 이력을 함께 전달

## 제한 사항

현재 세션에서는 in-app browser backend가 연결되지 않아 화면 캡처 기반 브라우저 QA를 완료하지 못했다. 대신 Python 서버와 패키지 실행 파일을 별도 포트에서 직접 실행하고 API·정적 자산 포함 여부를 검증했다. 브라우저 연결이 복구되면 다음 항목을 캡처 회귀 테스트한다.

1. Strategy Brief 전체 화면의 다크 테마 대비와 차트 레이블 겹침 여부
2. 2개 기업 선택 시 블루·레드 색상 매핑
3. 2026(E) 전망 밴드와 해칭 막대의 구분
4. 650px 이하 화면에서 차트 축·범례·카드의 가독성
5. AI provider 미연결/연결 상태별 결과 패널
