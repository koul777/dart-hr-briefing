## 14. ai

```text
HR Analytics Assistant를 구현해줘.

연결 계약:
- 브라우저는 POST /api/ai/briefing으로 검증된 payload만 보낸다.
- Provider는 OpenAI Responses API이며 모델은 OPENAI_MODEL을 사용한다.
- 개인 키는 password 입력 → X-OpenAI-API-Key 헤더 → 서버 요청 메모리에서만 사용한다.
- 개인 키가 없으면 서버의 OPENAI_API_KEY를 사용한다.
- 키를 localStorage·로그·응답·오류문에 저장하거나 출력하지 않는다.

답변을 확인된 사실, 계산 결과, 해석, 추가 확인 정보로 구분해줘.
공시만으로 인과관계를 단정하거나 개인 평가·채용·보상·감축을 권고하지 못하게 하고,
근거 ID와 한계를 표시해줘. 연결 실패·인증 실패·모델 실패도 구분해줘.
```
