AI 연결 2 · 서버 Provider 호출

서버가 Responses API를 호출해 답변만 반환한다

# server.py · POST /api/ai/briefing
header_key = self.headers.get("X-OpenAI-API-Key")
key = header_key or OPENAI_API_KEY
body = json.dumps({
  "model": OPENAI_MODEL,
  "input": briefing_prompt(payload)
}).encode("utf-8")
request = Request(
  "https://api.openai.com/v1/responses",
  data=body, method="POST",
  headers={"Authorization": f"Bearer {key}",
           "Content-Type": "application/json"}
)
result = json.load(urlopen(request, timeout=30))
answer = extract_output_text(result)
self.send_json({"answer": answer})
모델OPENAI_MODEL=gpt-5.6-luna
키 수명현재 HTTPS 요청 처리 동안만 메모리에 존재
반환검증된 답변 텍스트와 근거 ID만
