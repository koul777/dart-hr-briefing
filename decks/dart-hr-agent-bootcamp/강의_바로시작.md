# 강의 바로 시작

1. 도입에서는 오늘 만들 순서와 제출 증거만 확인하고 완성 화면은 2분 안에 닫습니다.
2. MODULE 01에서 OpenDART 키 발급, .env 입력, 서버와 Claude Code 실행을 화면 공유하며 직접 시연합니다.
3. MODULE 02에서는 전체 프롬프트를 한 개씩 붙여넣고 화면 뼈대→기업 선택→기간 선택이 자라는 과정을 확인합니다.
4. MODULE 03에서는 브라우저→Python 서버→OpenDART와 AI Provider 요청을 코드·URL·JSON으로 확인한 뒤 지표와 브리핑을 추가합니다.
5. MODULE 04에서 GitHub와 Vercel을 실제로 연결하고 공개 URL에서 같은 조작을 재현합니다.

## 화면 공유 원칙
- 실제 API 키, .env 값, 요청 헤더는 공유하지 않습니다.
- 강사는 키를 미리 설정한 별도 데모 환경을 사용합니다.
- 외부 API가 실패하면 저장소 루트의 검증된 완성본과 준비된 응답 캡처로 설명을 이어가고, 수강생 작업은 보존합니다.
