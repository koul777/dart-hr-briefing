# DART HR Analytics Agent 4시간 강의 — 바로 시작

## 1. 강의 파일

- `DART_HR_Analytics_Agent_4시간_강의.pdf` — 발표용 기본 파일
- `DART_HR_Analytics_Agent_4시간_강의.pptx` — PowerPoint용 이미지 기반 백업
- `viewer.html` — 브라우저 발표 및 슬라이드 확인
- `speaker-notes.md` — 슬라이드별 진행 멘트와 시간
- `participant-prompts.md` — 수강생이 순서대로 입력할 Claude Code 프롬프트 18개
- `slide-outline.md` — 전체 46장 구성과 학습 목표

## 2. 수업 전 10분 점검

프로젝트 루트에서 다음 명령을 실행합니다.

```powershell
py -3.12 -X utf8 tools\classroom_preflight.py
python server.py
```

브라우저에서 `http://127.0.0.1:8765`를 연 뒤 다음을 확인합니다.

1. 사전점검 결과가 `FAIL 0`이다.
2. 첫 화면에서 **합성 샘플로 시작**을 누를 수 있다.
3. 두 가상 기업과 `SAMPLE` 표시가 보인다.
4. Compare, Strategy Brief, AI 브리핑 화면이 열린다.
5. 합성 모드에서 실제 기업·개인 데이터와 외부 API 호출을 사용하지 않는다.

실제 OpenDART 조회를 시연할 때만 `.env`에 `OPENDART_API_KEY`를 설정합니다. 키 값은 화면, 코드, GitHub, 캡처에 표시하지 않습니다.

## 4. 화면 시연 순서

1. 완성본을 3분 안에 먼저 보여줍니다.
2. **합성 샘플로 시작**을 누릅니다.
3. 기업·연도·보고서 선택 상태를 확인합니다.
4. Compare에서 직원수·급여·매출·생산성 지표를 확인합니다.
5. Strategy Brief에서 사실·계산·해석·가설·근거 ID를 구분합니다.
6. AI 브리핑에서 “두 기업의 인력 생산성 차이를 설명해줘”를 실행합니다.
7. 슬라이드 34–37을 따라 GitHub 저장소 생성과 첫 push를 완료합니다.
8. 슬라이드 38–42를 따라 Vercel Import, 설정, 환경변수, 배포, 운영 검증을 완료합니다.
9. 슬라이드 43–45에서 자동 재배포, 장애 복구, m4 제출 기준을 확인합니다.

슬라이드에 사용한 프로그램 화면은 현재 소스 빌드를 직접 조작해 캡처했습니다. 캡처 계약은 `assets/current/capture-manifest.json`에서 확인할 수 있습니다.

## 5. 강사 운영 원칙

- 수강생은 완성본 전체를 새로 만들지 않고 Starter에서 핵심 기능 네 개를 붙입니다.
- AI에게 수정 전에 관련 파일, 변경 계획, 완료 기준을 먼저 설명하게 합니다.
- 실제 0과 데이터 없음, 종목코드와 `corp_code`, 연결과 별도 기준을 구분합니다.
- AI에는 원문 전체 대신 서버에서 검증한 구조화 데이터와 근거 ID를 전달합니다.
- 공시만으로 인과를 단정하거나 개인 평가·채용·보상 결정을 제안하지 않습니다.
